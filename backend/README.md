# Automata Backend

Automata is a robust, event-driven browser automation and semantic extraction engine. It leverages FastAPI, Playwright, and PostgreSQL to execute asynchronous web scraping jobs. Unlike traditional scrapers, Automata uses a **semantic, container-first heuristic engine** that adapts to any website's structure without requiring domain-specific hardcoding.

## Features

- **Semantic Extraction Engine**: Goal-routed extraction (e.g., "products", "headlines", "quotes") that dynamically scores and detects repeated DOM containers without site-specific selectors.
- **Asynchronous Execution**: Fully asynchronous job processing queue managed via `asyncio.Queue` and Semaphores to control concurrency limits.
- **Real-Time Observability**: Live execution logs, extraction previews, and screenshots streamed to clients via WebSockets (`/jobs/ws/{id}`).
- **Containerized**: Fully Dockerized with pre-configured Chromium dependencies and PostgreSQL database orchestration.
- **Robust Fallbacks**: Intelligent fallback to automated pattern discovery if specific semantic goals aren't matched.

## Tech Stack

- **Framework**: FastAPI
- **Browser Automation**: Playwright (Async API)
- **Database**: PostgreSQL
- **ORM**: SQLAlchemy
- **Realtime**: WebSockets
- **Containerization**: Docker & Docker Compose

## Prerequisites

- Docker and Docker Compose (Recommended)
- Python 3.9+ (For local development)
- PostgreSQL (For local development)

## Quick Start (Docker)

The easiest way to run the backend is using Docker Compose, which handles spinning up the PostgreSQL database, installing Playwright system dependencies, and starting the FastAPI server.

1. Create your environment file:
   ```bash
   cp .env.example .env
   ```
2. Start the services:
   ```bash
   docker-compose up --build
   ```

The backend will be available at `http://localhost:8000`.

## Local Development (Without Docker)

If you prefer to run the server locally without Docker:

1. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: .\venv\Scripts\activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Install Playwright browsers and dependencies:
   ```bash
   playwright install chromium
   playwright install-deps chromium
   ```
4. Setup your `.env` file with a local PostgreSQL connection string.
5. Run the FastAPI server:
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

## Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `POSTGRES_USER` | Database username | `user` |
| `POSTGRES_PASSWORD` | Database password | `password` |
| `POSTGRES_DB` | Database name | `automata` |
| `DATABASE_URL` | Full SQLAlchemy connection string | `postgresql://user:password@db:5432/automata` |

## Core Architecture

- `app/main.py`: Application entry point and route registration.
- `app/api/routes/jobs.py`: REST and WebSocket endpoints for job creation and monitoring.
- `app/automation/playwright_service.py`: The core semantic extraction engine. Uses `GoalRoute` to map user intent to DOM analysis strategies.
- `app/automation/event_emitter.py`: Unified logging and WebSocket broadcasting layer.
- `app/queue/worker.py`: Background job consumer using `asyncio.Semaphore`.
- `app/db/`: Database models and SQLAlchemy session management.
